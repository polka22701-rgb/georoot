# Roadmap

## v0.1 Project skeleton

Verify the Fabric 26.1.2 template, Java 25 settings, Fabric API dependency, entrypoints, and launch tasks.

## v0.2 Architecture skeleton

Add minimal package organization for future worldgen work without registering terrain, biomes, features, or surface rules.

## v0.3 Datagen dry run

Wire Fabric datagen so it can run safely without producing terrain-affecting JSON.

## v0.4 Docs and safety rules

Document architecture, safety rules, worldgen layers, and release expectations.

## v0.5 First inactive worldgen JSON experiment

Plan or generate a georoot-namespaced test resource that is not referenced by vanilla overworld generation.

## v0.6 First disposable-world test

Only after explicit approval, test a reversible experiment in a disposable world or isolated preset.

## Later stages

Later terrain, biome, feature, surface, and compatibility work requires explicit approval for each mutation step.
