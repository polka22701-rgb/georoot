# Worldgen Layers

## Terrain layer

Future terrain work may use `noise_settings` and `density_function` resources. This layer is not implemented yet.

## Feature and tree layer

Future tree and feature work may use `configured_feature` and `placed_feature` resources. This layer is not implemented yet.

## Biome layer

Future biome work may use biome bootstrap code or Fabric biome modification APIs. This layer is not implemented yet.

## Surface layer

Future surface work may use surface rules after review. This layer is not implemented yet.

## Diagnostics layer

Future diagnostics may include debug commands, focused logs, CSV exports, or overlays for terrain analysis. This layer is not implemented yet.

## Compatibility goal

GeoRoot should remain terrain-first and keep vanilla biomes unless a later step explicitly changes that goal.
